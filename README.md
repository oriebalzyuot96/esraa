# Esraa Nasser · إسراء ناصر

**Senior Software Engineer · .NET Core · Blazor · System Integrations**

Bilingual (English / Arabic RTL) portfolio built with Astro: accessible light/dark themes, a 40-second intro video with an original soundtrack, and a downloadable CV.

- 🌐 Live: https://oriebalzyuot96.github.io/esraa/ · Arabic: https://oriebalzyuot96.github.io/esraa/ar/
- 📄 CV: https://oriebalzyuot96.github.io/esraa/Esraa-Nasser-CV.pdf
- 🎬 Intro video: https://oriebalzyuot96.github.io/esraa/assets/esraa-intro.mp4

## Highlights
- **Saudi Azm**: Contracts (CSP) e-signature platform integrated with Emdha and DMS; Noug and Whis Book app back ends.
- **Link Development**: project-management tools on SharePoint and Microsoft 365.
- **ITWorx Education**: winjiGo and TeacherKit e-learning.
- **INTDV**: Arabic chatbot back ends with IBM Watson.

## Develop
```bash
npm install
npm run dev      # http://localhost:4321/esraa/
npm run build
```
- `src/data/profile.ts` holds all content in English and Arabic.
- `tools/cv/cv.html` renders `public/Esraa-Nasser-CV.pdf`.
- `tools/reel/` renders the intro video and its synthesised music.
